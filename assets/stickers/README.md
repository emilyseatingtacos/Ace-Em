# Travis Strean — Unhinged Punk Rock Sticker Asset Set

This pack includes a transparent-background **8x10 inch** sticker sheet plus **15 individual sticker SVGs** designed for printable transparent sticker paper.

## Files
- `travis-strean-unhinged-8x10-template.svg` — 8x10 sheet with 15 stickers arranged 3x5.
- `individual/sticker-01.svg` ... `individual/sticker-15.svg` — standalone sticker assets.

## Style Notes
- Theme: punk rock, unhinged, funny dark humor.
- Main name/topic integrated: **Travis Strean**.
- Transparent canvas (no full-page background) for clear sticker stock compatibility.

## Print Tips
- Import SVG into Cricut Design Space, Silhouette Studio, Canva, or Adobe Illustrator.
- Keep sheet at exactly 8x10 inches for predictable cuts.
- Add cut lines/bleed in your cutter software if needed.
