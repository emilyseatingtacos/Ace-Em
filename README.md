# Ace-Em

A lightweight Rust command-line application scaffold.

## Getting Started
1. Ensure you have Rust installed (https://www.rust-lang.org/tools/install).
2. Build the project:
   ```bash
   cargo build
   ```
3. Run the CLI with help output:
   ```bash
   cargo run -- --help
   ```

## Usage
- Show basic info:
  ```bash
  cargo run --
  ```
- Greet yourself:
  ```bash
  cargo run -- greet --name "Your Name"
  ```

The CLI is intentionally minimal and ready for future Ace-Em features.
